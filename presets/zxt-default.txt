# ============================================================
# ZXT macOS Debloat
#
# Aggressive daily-use preset.
#
# Goal:
# Remove genuinely optional background services without
# disabling important macOS frameworks, graphics/UI services,
# scheduling infrastructure, Spotlight internals or system
# performance infrastructure.
#
# IMPORTANT:
# This preset intentionally DOES NOT disable:
#
# WindowServer
# corespotlightd
# spotlightknowledged
# mds / mdworker
# contextstored
# coreduetd
# duetexpertd
# BiomeAgent / biomed / biomesyncd
# GamePolicyAgent / gamepolicyd
# QuickLook ThumbnailsAgent
# diagnosticd
# spindump
# perfpowermetricd
# powerlogHelperd
# mlhostd
# generic NaturalLanguage/ML runtimes
# Safari runtime/security services
#
# ============================================================
